## 3. 并行化反模式是如何抬高账单的？

## 4. 可缓存前缀中的动态内容反模式是什么？

- **B** 使用过短的系统提示
- **C** 把工具 schema 放进前缀里
- **D** 总是流式返回响应

## 5. batch + 缓存输入如何在夜间叠加以削减成本？

- **A** batch API 给 50% 折扣；缓存输入再叠加约 10 倍优势；两者结合，夜间流水线可降至同步无缓存成本的约 10%
- **B** batch 只节省输出成本
- **C** batch 与缓存不兼容
- **D** 缓存会让请求失去 batch 资格

</details>

## 6. 对于语义缓存「95% 准确率」的宣称，本课怎么说？

- **A** 95% 指的是匹配正确率，而非命中率；据报告，生产环境命中率从约 10%（开放对话）到约 70%（结构化 FAQ）不等
- **B** 95% 意味着你应当预期 95% 的缓存命中
- **C** 95% 是厂商文档记录的命中率基线
- **D** 95% 是 OpenAI 的默认缓存命中率
