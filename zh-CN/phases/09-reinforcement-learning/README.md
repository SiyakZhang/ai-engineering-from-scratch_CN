# 阶段 9：强化学习

> agent 在行动中学习。RLHF 的基础。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 1 的概率与分布，以及阶段 2 第 01 课的机器学习分类体系。

**第一课：** [MDP、状态、动作与奖励](01-mdps-states-actions-rewards/docs/zh.md)

从仓库根目录运行：

```bash
python3 phases/09-reinforcement-learning/01-mdps-states-actions-rewards/code/main.py
```

记录命令、退出码、随机和贪心策略的回报、价值网格，以及一句把策略质量与期望回报联系起来的说明。

**下一步：** 改变折扣因子，预测价值变化，然后继续学习[动态规划](02-dynamic-programming/docs/zh.md)。
