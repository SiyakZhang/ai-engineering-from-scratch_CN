## 1. 什么是马尔可夫性质？

- **A** 过程必须有有限数量的状态
- **B** 下一个状态只取决于当前状态，而不取决于之前状态的历史
- **C** 在每一步所有状态都是等可能的
- **D** 过程总是回到它的初始状态

<details>
<summary>查看答案与解析</summary>

**答案**　B

马尔可夫性质（无记忆性）意味着 P(X_{t+1} = j | X_t = i, X_{t-1}, ...) = P(X_{t+1} = j | X_t = i)。未来只取决于你现在在哪里，而不取决于你如何到达那里。这使得可以用一个转移矩阵进行紧凑表示。

</details>

## 2. 在一维随机游走中，离原点的期望距离如何随步数 n 变化？

- **A** 线性地：与 n 成正比
- **B** 对数地：与 log(n) 成正比
- **C** 无论 n 如何它都保持恒定
- **D** 按平方根：与 sqrt(n) 成正比

<details>
<summary>查看答案与解析</summary>

**答案**　D

每一步以相等概率取 +1 或 -1。n 步后的方差为 n，因此标准差（离原点的典型距离）为 sqrt(n)。走 10,000 步后，期望距离约为 100，而不是 10,000。

</details>

## 3. 马尔可夫链的平稳分布是什么？

- **A** 在转移矩阵作用下不发生变化的分布：pi * P = pi
- **B** 所有状态上的均匀分布
- **C** 恰好一次转移后的状态分布
- **D** 状态的初始分布

<details>
<summary>查看答案与解析</summary>

**答案**　A

平稳分布 pi 满足 pi * P = pi——施加转移矩阵后它保持不变。它表示长期来看在每个状态停留的时间比例。对于不可约、非周期的链，任何初始分布都会收敛到 pi。

</details>

## 4. 在朗之万动力学 x_{t+1} = x_t - dt * grad(U) + sqrt(2*T*dt) * z 中，当温度 T 趋近于 0 时会发生什么？

- **A** 过程发散到无穷
- **B** 过程变成纯随机游走
- **C** 过程变成纯梯度下降（确定性优化）
- **D** 过程冻结在初始位置

<details>
<summary>查看答案与解析</summary>

**答案**　C

当 T = 0 时，噪声项 sqrt(2*T*dt)*z 消失，只剩下 x_{t+1} = x_t - dt * grad(U)，这就是标准梯度下降。当 T 很高时，噪声占主导，过程几乎是随机游走。中等的 T 在探索与利用之间取得平衡。

</details>

## 5. 在扩散模型中，前向过程在 T 步内对数据样本做了什么？

- **A** 它施加学习到的变换来生成新数据
- **B** 它沿着一条马尔可夫链逐步添加高斯噪声，直到样本变成纯噪声
- **C** 它把图像压缩到更低的分辨率
- **D** 它在每一步去除噪声从而锐化图像

<details>
<summary>查看答案与解析</summary>

**答案**　B

前向过程是一条马尔可夫链：x_t = sqrt(alpha_t) * x_{t-1} + sqrt(1 - alpha_t) * noise。经过 T 步后，x_T 约等于 N(0, I)——纯高斯噪声。然后反向过程（由神经网络学习）逐步去噪以生成新数据。

</details>
