# 阶段 1：数学基础

> 每个 AI 算法背后的直觉，用代码理解，不靠死啃教材。

## 在 GitHub 上开始本阶段

**前置要求：** 完成阶段 0，或确认能从仓库根目录使用 Python 3.11+ 和 Git。

**第一课：** [线性代数直觉](01-linear-algebra-intuition/docs/zh.md)

从仓库根目录运行：

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

记录命令、退出码、归一化向量输出、投影残差，以及一句解释：为什么矩阵乘向量就是神经网络的一层。

**下一步：** 改一个输入向量，先预测结果，再运行一次；然后继续学习[向量、矩阵与运算](02-vectors-matrices-operations/docs/zh.md)。

浏览[阶段 1 的完整课程列表](../../README.md#phase-1)或[跨阶段路线图](../../ROADMAP.md)。
