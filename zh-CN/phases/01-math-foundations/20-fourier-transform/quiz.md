# 傅里叶变换 · 自测

## 1. 傅里叶变换对信号做了什么？

- **A** 从信号中去除噪声
- **B** 压缩信号以使用更少存储
- **C** 把信号分解为不同频率、幅度和相位的正弦波
- **D** 把信号从模拟转换为数字

<details>
<summary>查看答案与解析</summary>

**答案**　C

傅里叶变换把信号从时域转换到频域。每个频率系数 X[k] 告诉你频率 k 处正弦波的幅度和相位。信号被重新表示为这些正弦波之和。

</details>

## 2. 快速傅里叶变换（FFT）相比直接 DFT 的时间复杂度是多少？

- **A** 两者都是 O(N^2)
- **B** FFT 是 O(N log N)，DFT 是 O(N^2)
- **C** FFT 是 O(N)，DFT 是 O(N log N)
- **D** FFT 是 O(log N)，DFT 是 O(N)

<details>
<summary>查看答案与解析</summary>

**答案**　B

直接 DFT 计算 N 个输出，每个都对 N 个输入求和：O(N^2)。Cooley-Tukey FFT 递归地把信号分成偶/奇两半，在 log2(N) 个层级上各做 O(N) 的工作，得到 O(N log N)。对于 N = 100 万，这是 2000 万次对 1 万亿次运算之比。

</details>

## 3. 卷积定理陈述了什么？

- **A** 时域中的卷积等于频域中的加法
- **B** 时域中的卷积等于频域中的逐点乘法
- **C** 卷积总是增加信号的长度
- **D** 卷积和相关是完全相同的运算

<details>
<summary>查看答案与解析</summary>

**答案**　B

卷积定理表明，时域中的卷积等于频域中的逐点乘法：x * h = IFFT(FFT(x) . FFT(h))。这就是为什么对于大卷积核，基于 FFT 的卷积是 O(N log N) 而不是 O(N*M)。

</details>

## 4. 为什么在 FFT 之前对信号做零填充不会提高真正的频率分辨率？

- **A** FFT 算法会忽略零填充的样本
- **B** 零填充引入的噪声抵消了这一改进
- **C** 零填充只对 2 的幂的信号长度有效
- **D** 零填充在已有频率分箱之间做插值，但无法揭示原始样本中不存在的频率细节

<details>
<summary>查看答案与解析</summary>

**答案**　D

真正的频率分辨率取决于观测时间 T = N/fs。零填充会增加更多频率分箱（更细的网格），但只是对已有频谱做插值——它让结果看起来更平滑，却无法分辨间隔小于 1/T Hz 的频率。

</details>

## 5. 在最初 Transformer 的正弦位置编码中，为什么不同的维度对被赋予几何间隔的频率？

- **A** 每个频率提供不同的分辨率——高频编码精细位置，低频编码粗略位置，从而给每个位置一个独特的指纹
- **B** 它确保所有编码值都在 0 和 1 之间
- **C** FFT 算法要求采用几何间隔
- **D** 它降低了 attention 的计算成本

<details>
<summary>查看答案与解析</summary>

**答案**　A

高频维度随位置快速变化（精细分辨率），而低频维度变化缓慢（粗略分辨率）。多频率编码合在一起给每个位置一个独特的模式——类似于傅里叶系数如何唯一地标识一个信号。

</details>
