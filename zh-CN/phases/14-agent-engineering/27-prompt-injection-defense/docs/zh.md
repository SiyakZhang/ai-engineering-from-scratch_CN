# Prompt injection（提示注入）防御

> 本节是中文防御与评估导读。

用户希望智能体完成一个任务，但检索到的网页、文件或历史记忆也可能包含看起来像指令的文本。应用必须能分辨是谁发出的请求，以及该主体有权做什么。

## Prompt–Validator–Executor（提示、校验、执行）

模型先提出动作。校验器核对调用者身份、用户意图、参数类型、资源范围和输出目的地，执行器只接收授权通过的动作。涉及敏感操作时，将批准绑定到实际参数。每次工具调用都要经过这条路径，单靠最终答案审核无法撤销已经发生的副作用。

## 阅读练习

对“给我概括这份文档”的请求分别评估读取、摘要、发送邮件三个操作。说明哪些属于用户已授权范围，哪些需要另外批准，并为每个结论写一个可验证的测试断言。
