# 编写保留判断空间的规格说明 · 自测

每题先选答案，再展开解析。

## 1. 欠规格与过度规格之间有用的中间地带是什么？

- **A** 更长的请求
- **B** 没有计划
- **C** 完整的实现脚本
- **D** 固定不变量和证据、同时保留可逆选择的可执行契约

<details>
<summary>查看答案与解析</summary>

**答案**　D

契约约束结果和风险，但不把每个实现细节写成脚本。

</details>

## 2. 哪种决定通常应锁定？

- **A** 可逆的文件拆分
- **B** 私有辅助函数的顺序
- **C** 系统是否可以写生产环境
- **D** 局部变量名

<details>
<summary>查看答案与解析</summary>

**答案**　C

权限和高后果行为需要人拥有决定权。

</details>

## 3. 什么是有界决定？

- **A** agent 不能行动
- **B** agent 可以在明确的安全限制内选择
- **C** 没有证明
- **D** 选择随机

<details>
<summary>查看答案与解析</summary>

**答案**　B

边界既保留有用判断，也让风险受控。

</details>

## 4. 为何将示例与不变量配对？

- **A** 示例证明每条普遍规则
- **B** 示例揭示意图，不变量说明必须始终成立的条件
- **C** 替代结果
- **D** 消除全部歧义

<details>
<summary>查看答案与解析</summary>

**答案**　B

具体案例和普遍约束发挥不同作用。

</details>

## 5. 什么证明能匹配用户旅程主张？

- **A** 浏览器或端到端旅程观察
- **B** 类型注解
- **C** 仅局部单元测试
- **D** 计划

<details>
<summary>查看答案与解析</summary>

**答案**　A

证明必须运行在与主张相同的层。

</details>

## 6. 为何记录锁定决定的理由？

- **A** 阻止所有变更
- **B** 让文件更长
- **C** 隐藏不确定性
- **D** 使后续证据无需考古即可修订选择

<details>
<summary>查看答案与解析</summary>

**答案**　D

可追溯的理由让规格能有意识地演进。

</details>
