# 通过隔离与合并契约委派 agent 工作 · 自测

每题先选答案，再展开解析。

## 1. 何时适合并行委派？

- **A** 只处理文档时
- **B** 只要有更多 agent
- **C** 每项超过十分钟的任务
- **D** 工作在决定、路径或等待时间上真正独立时

<details>
<summary>查看答案与解析</summary>

**答案**　D

只有单元无需共享可变决定或所有权也能推进时，并行才有帮助。

</details>

## 2. 文件系统隔离不能保证什么？

- **A** 独立目录
- **B** 独立执行命令
- **C** 独占的设计和路径所有权
- **D** 可恢复分支

<details>
<summary>查看答案与解析</summary>

**答案**　C

两个隔离的 worktree 仍可能实现冲突的设计。

</details>

## 3. 为什么每个工作单元必须写明证明？

- **A** 避免交接
- **B** 增加并发
- **C** 让执行者可以宣称成功
- **D** 让集成者获得可复现证据

<details>
<summary>查看答案与解析</summary>

**答案**　D

集成者必须验证结果，不能信任总结。

</details>

## 4. 两个单元拥有重叠路径时该怎么办？

- **A** 不审阅就合并
- **B** 更快运行它们
- **C** 让最后一位执行者获胜
- **D** 阻止并重新设计拆分

<details>
<summary>查看答案与解析</summary>

**答案**　D

重叠写入所有权会制造本可避免的冲突和歧义。

</details>

## 5. 什么是校准后的自主性？

- **A** 完全自动化
- **B** 只做手工工作
- **C** 证据和回滚充分时给自由，后果高时设检查点
- **D** 随机批准

<details>
<summary>查看答案与解析</summary>

**答案**　C

权限应跟随后果和可逆性。

</details>

## 6. 集成者最终负责什么？

- **A** 重写每个单元
- **B** 删除交接
- **C** 选择更大的模型
- **D** 运行完整跨单元验证关卡并执行范围约束

<details>
<summary>查看答案与解析</summary>

**答案**　D

单元证明不能取代端到端集成证据。

</details>
