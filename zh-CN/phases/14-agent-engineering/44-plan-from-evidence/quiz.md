# 制定由证据支撑的执行计划 · 自测

每题先选答案，再展开解析。

## 1. 执行计划与待办清单的区别是什么？

- **A** 带证据和证明的依赖图
- **B** 模型建议
- **C** 固定步骤数量
- **D** 更多散文

<details>
<summary>查看答案与解析</summary>

**答案**　A

依赖、凭据和完成证明让计划可执行、可恢复。

</details>

## 2. 为何在实现前定义共享契约？

- **A** 让只有一个 agent 工作
- **B** 推迟所有工作
- **C** 让依赖接触面不发明冲突行为
- **D** 避免文档

<details>
<summary>查看答案与解析</summary>

**答案**　C

固定的契约会解除依赖接触面安全并行的阻塞。

</details>

## 3. 依赖环通常揭示什么？

- **A** 强证据
- **B** 良好的并行性
- **C** 隐藏的未决决定或错误拆分
- **D** 快速执行

<details>
<summary>查看答案与解析</summary>

**答案**　C

循环工作项无法建立有效的起点。

</details>

## 4. 两个工作项何时可处于同一执行波次？

- **A** 依赖已完成且彼此独立时
- **B** 两者都重要时
- **C** 它们触碰同一文件时
- **D** 两者都没有证明时

<details>
<summary>查看答案与解析</summary>

**答案**　A

一个波次包含所有当前已解除阻塞且相互独立的工作。

</details>

## 5. 为什么每个工作项都要附证据？

- **A** 替代测试
- **B** 说明改动为何属于这里，并让新证据可以修订它
- **C** 满足 token 目标
- **D** 装饰计划

<details>
<summary>查看答案与解析</summary>

**答案**　B

证据既要证明计划合理，也应有能力改变计划。

</details>

## 6. 什么让计划可恢复？

- **A** 很长的初始 prompt
- **B** 一位执行者做完一切
- **C** 带状态、产物、依赖和证明的小工作项
- **D** 聊天历史

<details>
<summary>查看答案与解析</summary>

**答案**　C

持久的工作项状态让另一会话无需重新发现就能继续。

</details>
