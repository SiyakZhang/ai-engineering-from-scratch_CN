## 1. 反馈何时成为基础设施？

- **A** 出现在仪表盘时
- **B** 被总结时
- **C** 有通向负责的持久变更和验证的路径时
- **D** 被收集时

<details>
<summary>查看答案与解析</summary>

**答案**　C

提升和所有权把观察转成系统学习。

</details>

## 2. 一次生产写入尝试应路由到哪里？

- **A** 策略或权限边界
- **B** 只写文档
- **C** 通用待办列表
- **D** 视觉设计

<details>
<summary>查看答案与解析</summary>

**答案**　A

不安全权限由可执行的策略层拥有。

</details>

## 3. 误报首先应改变什么？

- **A** 部署区域
- **B** 团队名称
- **C** 定价
- **D** 评估或测试覆盖

<details>
<summary>查看答案与解析</summary>

**答案**　D

评估层应把失败保留为可复现案例。

</details>

## 4. 为何负责人是控制的一部分？

- **A** 隐藏信号
- **B** 增加会议
- **C** 无人负责的改进不会可靠改变或保持当前
- **D** 移除证明

<details>
<summary>查看答案与解析</summary>

**答案**　C

必须有人实现、验证、复审并淘汰行动。

</details>

## 5. 控制何时应淘汰？

- **A** 添加后立即
- **B** 从不
- **C** 证据显示它被取代、已过时或制造的摩擦超过保护风险时
- **D** 感觉旧了时

<details>
<summary>查看答案与解析</summary>

**答案**　C

与提升一样，淘汰也应由证据支撑。

</details>

## 6. 塑造构建与编码 agent 反馈如何连接？

- **A** 它们不相连
- **B** 只有 prompt 重要
- **C** 只有指标重要
- **D** 产品证据改变结果和范围，agent 纠正改变工作台；事故可能改变两者

<details>
<summary>查看答案与解析</summary>

**答案**　D

两条路径都用同一套从证据到持久系统变更的棘轮。

</details>
