每题先选答案，再展开解析。

## 1. Society of Minds 协议让 N 个模型实例做什么？

- **A** 各自独立提出答案，然后在 R 轮中阅读并批评彼此的提议，直到收敛
- **B** 在共享数据集上训练
- **C** 每个跑一个不同的基准
- **D** 谈判价格

<details>
<summary>查看答案与解析</summary>

**答案**　A

N 个提议者、R 轮、互相批评、收敛，这是 Du 等人经典辩论的形态。

</details>

## 2. 为什么跨模型辩论（例如 ChatGPT + Bard）胜过单模型辩论？

- **A** 异质性减少了共有的盲点，使互相批评能抓住更多错误
- **B** 它更便宜
- **C** 厂商共享权重
- **D** 不同厂商在谈判价格

<details>
<summary>查看答案与解析</summary>

**答案**　A

混合模型带来独立的错误分布，这抬高了辩论的上限。

</details>

## 3. 相比全网格（full mesh），稀疏拓扑在 token 成本上的主要收益是什么？

- **A** 它移除了 LLM
- **B** 稀疏拓扑不需要模型
- **C** 每个辩论者只阅读一部分同伴，因此批评操作数下降而准确率常能持平
- **D** 稀疏拓扑使轮数翻倍

<details>
<summary>查看答案与解析</summary>

**答案**　C

稀疏（星形、环形、中心辐射）在许多任务上减少批评操作而不损失准确率。

</details>

## 4. 本课把哪种情况列为辩论有害的地方？

- **A** 传记生成
- **B** 开放式推理
- **C** 国际象棋走法的合法性
- **D** 一个简单的事实查找，因为一次查找比五次辩论更便宜

<details>
<summary>查看答案与解析</summary>

**答案**　D

对延迟和成本敏感的琐碎查找，并不能从 N x R 的辩论中获益。

</details>

## 5. 什么是收敛坍缩（convergence collapse）？

- **A** 进程崩溃
- **B** 所有 agent 收敛到第一个错误答案上；用要求出现分歧的轮次来缓解
- **C** TLS 握手失败
- **D** 网络中断

<details>
<summary>查看答案与解析</summary>

**答案**　B

早早在一个错误答案上达成一致，可通过强制第 1 轮提出不同提议来缓解。

</details>

## 6. 为什么 prompt 同质化会削弱辩论？

- **A** 它用太多 token
- **B** 它绕过了监督者
- **C** 它违反 Apache 2.0
- **D** 相同的 prompt 产生几乎相同的答案，抹掉了互相批评的信号

<details>
<summary>查看答案与解析</summary>

**答案**　D

多样化的 prompt（理想情况下还有多样化的模型）让提议分布保持宽广。

</details>

## 7. 按本课所说，哪种生产模式是辩论的一个变体？

- **A** 向量索引
- **B** 带综合（synthesis）步骤的 Anthropic orchestrator-workers
- **C** 仅 cron 的调度
- **D** 纯粹的单次 RAG

<details>
<summary>查看答案与解析</summary>

**答案**　B

带综合的 orchestrator-workers 在生产中是一种辩论形态的模式。

</details>
