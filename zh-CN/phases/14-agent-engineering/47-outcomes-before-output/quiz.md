# 在选择产出前定义结果 · 自测

每题先选答案，再展开解析。

## 1. 哪句话描述的是结果而非产出？

- **A** 部署向量数据库
- **B** 增加仪表盘
- **C** 保持只读的同时，在两分钟内识别故障服务
- **D** 构建一个事故助手

<details>
<summary>查看答案与解析</summary>

**答案**　C

这句话描述可观察变化和约束，而没有固定产物。

</details>

## 2. 为什么实现越快，塑造风险越高？

- **A** 代码会变慢
- **B** 模型不再规划
- **C** 测试变得不可能
- **D** 团队可能在学习赶上前承诺错误问题

<details>
<summary>查看答案与解析</summary>

**答案**　D

速度会放大尚未赢得方向的代价。

</details>

## 3. 结果框架应包含什么？

- **A** 仅功能
- **B** 模型和框架版本
- **C** 用户、情境、当前行为、期望结果、约束和非目标
- **D** 仅架构

<details>
<summary>查看答案与解析</summary>

**答案**　C

六个接触面把构建连到真实情境和边界。

</details>

## 4. 结果框架何时可以点名技术？

- **A** 只在标题中
- **B** 经验证的兼容性约束确实固定它时
- **C** 只要它流行
- **D** 每个目标中

<details>
<summary>查看答案与解析</summary>

**答案**　B

只有证据让技术成为真实约束时，才应写入技术。

</details>

## 5. 非目标的作用是什么？

- **A** 衡量成功
- **B** 替代约束
- **C** 列出未来梦想
- **D** 拒绝本切片中诱人的相邻工作

<details>
<summary>查看答案与解析</summary>

**答案**　D

具体的非目标让构建贴住当前结果。

</details>

## 6. 受约束的结果何时算失败？

- **A** 只在没有代码交付时
- **B** 实现改变时
- **C** 通过违反固定约束达到期望结果时
- **D** 记录非目标时

<details>
<summary>查看答案与解析</summary>

**答案**　C

约束是结果的一部分，不是可选的实现建议。

</details>
