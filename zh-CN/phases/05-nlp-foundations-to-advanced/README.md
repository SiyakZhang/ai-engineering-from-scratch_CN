# 阶段 5：NLP，从基础到进阶

> 语言是通往智能的接口。掌握其中的每一层。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 2 第 14 课“朴素贝叶斯”。第一课只需 Python 3.11+。

**第一课：** [文本处理](01-text-processing/docs/zh.md)

从仓库根目录运行：

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

记录命令、退出码、token 列表、词干、词形还原结果，以及一个词干提取丢失含义而词形还原保住含义的例子。

**下一步：** 加入一个带标点和不规则动词的句子，检查结果，然后继续学习[词袋模型与 TF-IDF](02-bag-of-words-tfidf/docs/zh.md)。

浏览[阶段 5 的完整课程列表](../../README.md#phase-5)或[跨阶段路线图](../../ROADMAP.md)。
