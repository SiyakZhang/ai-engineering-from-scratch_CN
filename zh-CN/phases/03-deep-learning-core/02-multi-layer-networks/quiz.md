# 多层网络与前向传播 · 自测

## 1. 在多层网络中，隐藏层的作用是什么？

- **A** 应用损失函数
- **B** 减少参数数量
- **C** 存储训练数据
- **D** 把输入变换为新的特征表示，从而能够形成非线性决策边界

<details>
<summary>查看答案与解析</summary>

**答案**　D

隐藏层应用权重、偏置和激活函数来创建新的特征表示。这些中间特征使网络能够学习单层无法学习的非线性映射。

</details>

## 2. 神经网络中的前向传播做什么？

- **A** 为反向传播计算梯度
- **B** 打乱训练数据
- **C** 将输入逐层推送以产生一个输出
- **D** 使用梯度更新权重

<details>
<summary>查看答案与解析</summary>

**答案**　C

前向传播是纯粹的计算：对每一层乘以权重、加上偏置、应用激活，并把结果传给下一层。前向传播期间不发生任何学习。

</details>

## 3. 对于一个接收来自 2 个神经元输入的、含 3 个神经元的层，权重矩阵的形状是什么？

- **A** (3, 2)
- **B** (2, 3)
- **C** (3, 3)
- **D** (2, 2)

<details>
<summary>查看答案与解析</summary>

**答案**　A

权重矩阵的形状为 (当前层神经元数, 上一层神经元数) = (3, 2)。每一行包含一个神经元对所有输入的权重。

</details>

## 4. 通用逼近定理保证了什么？

- **A** 一个含足够多神经元的单隐藏层可以逼近任何连续函数
- **B** 更深的网络总是优于更浅的网络
- **C** 任何网络都能在多项式时间内训练完成
- **D** 神经网络可以解决任何计算问题

<details>
<summary>查看答案与解析</summary>

**答案**　A

Cybenko（1989）证明，一个含一个隐藏层和足够多神经元的网络可以以任意期望的精度逼近任何连续函数。在实践中，更深的网络用更少的总参数就能达到同样效果。

</details>

## 5. 为什么 sigmoid 激活函数使学习成为可能，而感知机中使用的阶跃函数却不行？

- **A** sigmoid 输出负值
- **B** sigmoid 输出更大的值
- **C** sigmoid 处处平滑且可微，因此反向传播所需的梯度存在
- **D** sigmoid 计算更快

<details>
<summary>查看答案与解析</summary>

**答案**　C

阶跃函数几乎处处梯度为零，并且在阈值处梯度无定义。sigmoid 是平滑的，在每一点都有良定义的导数（s*(1-s)），这对基于梯度的学习至关重要。

</details>
