# 阶段 15：自主系统

> 无需人工干预也能安全运行的 agent。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 14 第 01 课“Agent 循环”。

**第一课：** [长周期 agent](01-long-horizon-agents/docs/zh.md)

从仓库根目录运行：

```bash
python3 phases/15-autonomous-systems/01-long-horizon-agents/code/main.py
```

记录命令、退出码、时间跨度预测、累积可靠性表，以及在开始长时运行前你会要求的一项运维控制措施。

**下一步：** 以不同的单步可靠性重算一条轨迹，然后继续学习[自学式推理](02-star-family-reasoning/docs/zh.md)。

浏览[阶段 15 的完整课程列表](../../README.md#phase-15)或[跨阶段路线图](../../ROADMAP.md)。
