# 阶段 6：语音与音频

> 人类沟通的另一半：听见、理解、说出。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 1 的向量、矩阵和概率知识。第一个演示只使用 Python 标准库。

**第一课：** [音频基础](01-audio-fundamentals/docs/zh.md)

从仓库根目录运行：

```bash
python3 phases/06-speech-and-audio/01-audio-fundamentals/code/main.py
```

记录命令、退出码、检测到的频率峰值、混叠频率，并解释为什么降采样前必须先运行低通滤波器。

**下一步：** 改变源音调并预测其混叠频率，然后继续学习[频谱图与 Mel 特征](02-spectrograms-mel-features/docs/zh.md)。
