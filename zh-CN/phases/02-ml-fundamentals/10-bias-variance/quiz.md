# 偏差-方差权衡 · 自测

每题先选答案，再展开解析。

## 1. 用线性模型去拟合一个明显弯曲（二次）的关系。哪个误差成分占主导？

- **A** 方差：模型随不同训练数据变化太大
- **B** 都不是：模型应该完美拟合
- **C** 偏差：模型太僵硬，无法捕捉真实的非线性模式
- **D** 不可约噪声：数据噪声太大

<details>
<summary>查看答案与解析</summary>

**答案**　C

无论看到多少数据，线性模型都无法捕捉二次曲线。这种由错误模型假设带来的系统性误差就是偏差。模型欠拟合。

</details>

## 2. 期望误差的偏差-方差分解有三项。哪一项是任何模型都无法降低的？

- **A** 偏差的平方
- **B** 三项都可降到零
- **C** 不可约噪声（sigma 平方）
- **D** 方差

<details>
<summary>查看答案与解析</summary>

**答案**　C

不可约噪声来自数据本身的随机性（测量误差、缺失变量）。任何模型都无法预测噪声。期望误差 = 偏差^2 + 方差 + 不可约噪声。

</details>

## 3. 向模型添加 L2 正则化会增加偏差并降低方差。这为什么有用？

- **A** 它使模型训练更快
- **B** 方差的降低可能超过偏差的增加，从而降低总误差
- **C** 它总能同时提升训练和测试准确率
- **D** L2 正则化消除了不可约噪声

<details>
<summary>查看答案与解析</summary>

**答案**　B

正则化用偏差的小幅增加换取方差的更大幅降低。当模型过拟合（高方差）时，尽管偏差略有上升，这种权衡仍能降低总误差。

</details>

## 4. 某模型训练误差 = 2%、测试误差 = 25%。最可能的诊断是什么？

- **A** 高偏差（欠拟合）：模型太简单
- **B** 高方差（过拟合）：模型记住了训练数据，无法泛化
- **C** 高不可约噪声：数据噪声太大
- **D** 模型校准完美

<details>
<summary>查看答案与解析</summary>

**答案**　B

低训练误差 + 高测试误差 + 巨大差距 = 高方差（过拟合）。模型拟合了训练专有的噪声。补救措施：正则化、降低复杂度、获取更多数据。

</details>

## 5. 你在 50 个不同的随机训练子集上训练相同的模型架构，发现它们之间的预测差异极大。这说明什么？

- **A** 高不可约噪声：目标变量是随机的
- **B** 学习率太高
- **C** 高方差：模型对它所看到的具体训练数据很敏感
- **D** 高偏差：模型一贯地错过真实模式

<details>
<summary>查看答案与解析</summary>

**答案**　C

方差衡量在不同数据子集上训练时预测变化的程度。各子集之间预测差异极大正是高方差的定义。

</details>
