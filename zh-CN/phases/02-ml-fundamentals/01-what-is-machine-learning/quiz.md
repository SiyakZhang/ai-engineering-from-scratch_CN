# 什么是机器学习 · 自测

每题先选答案，再展开解析。

## 1. 在监督学习中，模型在训练时会收到什么？

- **A** 提供了正确答案的输入-输出对
- **B** 只有输入数据，没有标签
- **C** 一组由人类专家编写的规则
- **D** 对每个所采取动作的奖励信号

<details>
<summary>查看答案与解析</summary>

**答案**　A

监督学习在输入-输出对（带标签数据）上训练。模型学习把输入映射到已知的正确输出。

</details>

## 2. 把数据分成训练集和测试集的目的是什么？

- **A** 为了评估模型是否能泛化到它在训练中从未见过的数据
- **B** 以便在训练数据丢失时有备份数据
- **C** 为了平衡数据集中的类别
- **D** 通过使用更少数据让训练更快

<details>
<summary>查看答案与解析</summary>

**答案**　A

测试集衡量泛化能力。如果你在训练数据上评估，衡量的是记忆而非学习。

</details>

## 3. 某模型在训练数据上达到 98% 准确率，但在测试数据上只有 55%。这是哪种情况的例子？

- **A** 数据漂移：测试分布发生了变化
- **B** 过拟合：模型记住了训练噪声，而不是学到通用模式
- **C** 欠拟合：模型太简单
- **D** 良好泛化：模型学到了真实模式

<details>
<summary>查看答案与解析</summary>

**答案**　B

训练准确率（高）与测试准确率（低）之间的巨大差距是过拟合的标志。模型只是记住了训练数据。

</details>

## 4. 某电商网站希望在没有任何预定义标签的情况下，根据购买行为把客户分组。这属于哪种类型的机器学习？

- **A** 监督学习（回归）
- **B** 强化学习
- **C** 监督学习（分类）
- **D** 无监督学习（聚类）

<details>
<summary>查看答案与解析</summary>

**答案**　D

在没有预定义标签的情况下寻找数据中的自然分组就是聚类，它是无监督学习的一种形式。

</details>

## 5. 以下哪个场景不是机器学习的良好用例？

- **A** 从历史行为数据预测客户流失
- **B** 把温度从摄氏度转换为华氏度
- **C** 把皮肤病变图像分类为良性或恶性
- **D** 在数百万笔支付流中检测欺诈交易

<details>
<summary>查看答案与解析</summary>

**答案**　B

摄氏度转华氏度是一个固定公式（F = 9/5 * C + 32）。简单、定义明确的规则不需要机器学习。在这里用机器学习只会增加复杂度而毫无益处。

</details>
