## 1. sigmoid 函数输出的取值范围是多少？

- **A** 0 到正无穷
- **B** -1 到 1
- **C** 0 到 1（开区间）
- **D** 负无穷到正无穷

<details>
<summary>查看答案与解析</summary>

**答案**　C

sigmoid 函数 1/(1+e^(-z)) 输出严格介于 0 和 1 之间的值，可被解释为概率。

</details>

## 2. 为什么逻辑回归被称为“回归”，尽管它用于分类？

- **A** 这个名字来自它所使用的逻辑（sigmoid）函数，而非来自回归分析
- **B** 它像线性回归一样最小化均方误差
- **C** 它预测连续值，然后再四舍五入
- **D** 它最初是为回归设计的，后来才被改用

<details>
<summary>查看答案与解析</summary>

**答案**　A

这个名字来自逻辑函数（sigmoid）。尽管名为回归，逻辑回归实际上是一种输出类别概率的分类算法。

</details>

## 3. 为什么逻辑回归使用二元交叉熵而不是 MSE？

- **A** MSE 只能用于线性模型
- **B** 交叉熵计算更快
- **C** 交叉熵只在数据集平衡时才有效
- **D** MSE 配合 sigmoid 会产生带有局部最小值的非凸代价曲面，而交叉熵是凸的

<details>
<summary>查看答案与解析</summary>

**答案**　D

MSE 与 sigmoid 激活相结合会产生带有许多局部最小值的非凸代价曲面。二元交叉熵配合 sigmoid 是凸的，保证只有一个全局最小值。

</details>

## 4. 一个垃圾邮件过滤器的精确率 = 0.95、召回率 = 0.60。这在实际中意味着什么？

- **A** 被标记的邮件中有 60% 是垃圾邮件，并捕获了 95% 的所有垃圾邮件
- **B** 当它把一封邮件标记为垃圾邮件时，有 95% 的概率是对的，但它只捕获了 60% 的真实垃圾邮件
- **C** 模型在测试集上准确率 95%、在训练集上 60%
- **D** 所有邮件中有 95% 被正确分类，并捕获了 60% 的垃圾邮件

<details>
<summary>查看答案与解析</summary>

**答案**　B

精确率 = 0.95 意味着被预测为垃圾邮件的邮件中有 95% 确实是垃圾邮件（误报很少）。召回率 = 0.60 意味着只有 60% 的真实垃圾邮件被捕获（40% 漏网）。

</details>

## 5. 在 4 类的 softmax 回归中，关于输出概率以下哪项是正确的？

- **A** 四个输出概率之和为 1，概率最高的类别即为预测结果
- **B** 每个类别都得到一个介于 0 和 1 之间的独立概率
- **C** 输出是原始分数，而非概率
- **D** 只有概率最高的前 2 个类别得到非零概率

<details>
<summary>查看答案与解析</summary>

**答案**　A

softmax 把一个原始分数向量转换为总和为 1 的概率。预测类别就是概率最高的那个。

</details>
