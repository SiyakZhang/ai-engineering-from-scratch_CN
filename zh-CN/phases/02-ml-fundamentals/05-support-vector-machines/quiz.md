# 支持向量机 · 自测

每题先选答案，再展开解析。

## 1. SVM 中的支持向量是什么？

- **A** 训练时学到的权重向量
- **B** 训练集中的所有数据点
- **C** 经过核变换后的特征向量
- **D** 距离决策边界最近、决定超平面的那些训练点

<details>
<summary>查看答案与解析</summary>

**答案**　D

支持向量是恰好位于间隔边界上的训练点。它们是唯一决定决策超平面的点。移除非支持向量的点不会改变边界。

</details>

## 2. SVM 在寻找决策边界时最大化什么？

- **A** 间隔——即决策边界与每个类别最近点之间的距离
- **B** 决策边界的复杂度
- **C** 所有点到边界的总距离
- **D** 被正确分类的训练点数量

<details>
<summary>查看答案与解析</summary>

**答案**　A

SVM 寻找使两个类别之间间隔最大化的超平面。更宽的间隔会带来在未见数据上更好的泛化。

</details>

## 3. 当你增大 SVM 中的 C 参数时会发生什么？

- **A** 间隔变宽，允许更多的误分类
- **B** 支持向量的数量总是增加
- **C** 核函数从线性变为 RBF
- **D** 间隔变窄，容忍的误分类更少，模型可能过拟合

<details>
<summary>查看答案与解析</summary>

**答案**　D

大的 C 会重罚误分类，产生紧贴训练数据的窄间隔。这可能导致过拟合。小的 C 允许更多违例，从而得到更宽、正则化更强的间隔。

</details>

## 4. 核技巧如何使 SVM 能够学习非线性边界？

- **A** 它用神经网络替换 SVM
- **B** 它直接向输入数据添加多项式特征
- **C** 它在高维空间中计算点积，而无需把数据显式映射到该空间
- **D** 它在训练前从数据集中移除异常值

<details>
<summary>查看答案与解析</summary>

**答案**　C

核技巧把每个点积 x_i . x_j 替换为 K(x_i, x_j)，在高维（对 RBF 而言甚至是无限维）特征空间中计算点积，而从不真正构造该空间。

</details>

## 5. 当 y * f(x) >= 1 时铰链损失为零。这在分类意义上意味着什么？

- **A** 该点恰好在决策边界上
- **B** 该点被误分类
- **C** 该点被正确分类且位于间隔之外
- **D** 该点是应被忽略的噪声样本

<details>
<summary>查看答案与解析</summary>

**答案**　C

当 y * f(x) >= 1 时，该点既被正确分类，又位于间隔边界上或之外。只有位于间隔内部或被误分类（y * f(x) < 1）的点才对铰链损失有贡献。

</details>
