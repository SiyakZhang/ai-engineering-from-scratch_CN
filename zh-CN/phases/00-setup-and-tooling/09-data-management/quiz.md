## 1. 在机器学习中，为什么要把数据分成独立的训练集、验证集和测试集？

- **A** 为了在未见过的数据上评估模型性能并防止过拟合
- **B** 为了确保每个数据集划分使用不同的文件格式
- **C** 为了把数据分配到多块 GPU 上
- **D** 为了让数据集变小，使训练更快

<details>
<summary>查看答案与解析</summary>

**答案**　A

训练集用于训练模型，验证集在训练过程中调整超参数，测试集在模型从未见过的数据上提供最终的无偏评估。

</details>

## 2. 在 AI/ML 工作流中，Hugging Face Hub 主要用来做什么？

- **A** 在云端运行 GPU 训练任务
- **B** 托管和共享数据集、模型以及 ML 产物
- **C** 管理 Python 虚拟环境
- **D** 像 GitHub 那样对源代码做版本控制

<details>
<summary>查看答案与解析</summary>

**答案**　B

Hugging Face Hub 是一个托管和共享预训练模型、数据集和 ML 演示的平台。'datasets' 库提供了一种从中加载数据的标准方式。

</details>

## 3. 在存储 ML 数据集时，Parquet 格式相比 CSV 有什么优势？

- **A** Parquet 文件在任何文本编辑器中都能让人读懂
- **B** Parquet 文件可以在电子表格应用中编辑
- **C** Parquet 比 CSV 支持更多的数据类型
- **D** Parquet 采用列式存储，文件更小、读取更快

<details>
<summary>查看答案与解析</summary>

**答案**　D

Parquet 是一种列式二进制格式，压缩率优于 CSV，并支持快速的列级读取。它是 ML 数据集的首选存储格式。

</details>

## 4. 用 Hugging Face datasets 库加载数据集时，'streaming=True' 有什么作用？

- **A** 当有新数据加入 Hub 时启用实时更新
- **B** 把数据集转换为流媒体视频格式
- **C** 使用并行连接更快地下载数据集
- **D** 逐行加载数据，无需把完整数据集下载到磁盘

<details>
<summary>查看答案与解析</summary>

**答案**　D

流式模式会创建一个按需获取数据行的 IterableDataset。无论数据集多大，内存占用都保持恒定，这对于大到无法放进磁盘的数据集至关重要。

</details>

## 5. 对于大文件，什么时候应该用 DVC（数据版本控制）而不是仅仅用 .gitignore？

- **A** 当你需要用带版本的数据在不同机器上复现完全一致的实验时
- **B** 当你独自做一个个人项目时
- **C** 当你的数据集小于 1 MB 时
- **D** 当你的项目里只有 CSV 文件时

<details>
<summary>查看答案与解析</summary>

**答案**　A

DVC 用 git 中的小型指针文件来追踪数据版本，而把实际数据存储在远程存储（S3、GCS）中。它确保任何人都能用相同的数据复现你完全一致的实验。

</details>
