# 认证测评 · 自测

每题先选答案，再展开解析。

## 1. 一位经理要求 Claude 制作兼具战略性和细节的发布计划。哪项修改最能改善请求？

- **A** 明确发布决策、受众、批准输入、约束、里程碑、风险、输出表格和验收检查
- **B** 让 Claude 给出定论计划、独立解决歧义并省略保留意见
- **C** 给出详细字数目标，让 Claude 覆盖其认为相关的所有发布主题，但不提供验收标准
- **D** 使用能力最强的模型并赋予发布策略师角色

<details>
<summary>查看答案与解析</summary>

**答案**　A

修改后的 prompt 把主观形容词改成输入和输出均可检查的任务契约。角色设定、字数目标和无法兑现的保证，都不能定义有效发布计划必须包含什么。

</details>

## 2. 一个 prompt 包含政策文本、客户消息和输出指令。哪两项改变最能减少歧义？选两个。

- **A** 明确证据冲突时哪个政策来源具有权威性
- **B** 用详细示例替代输出标准，让 Claude 推断哪些元素必需
- **C** 将政策和客户文本放在同一证据区，仅靠引号区分权威性而没有显式层级
- **D** 将每种内容放入清晰标注的区块

<details>
<summary>查看答案与解析</summary>

**答案**　A、D

标注边界区分指令与数据，权威规则解决冲突。混合内容会增加 prompt-injection 和解释风险，删除标准则失去评估基础。

</details>

## 3. Claude 必须将反馈标为正面、负面、混合或未知。哪组示例最有用？

- **A** 四条明显正面评论
- **B** 一个清晰案例，加上带正确标签的混合、边界和证据不足案例
- **C** 大量典型正负评论，均远离决策边界且按定义一致标注
- **D** 大量典型相关评论，没有正确标签或接近混合、未知边界的示例

<details>
<summary>查看答案与解析</summary>

**答案**　B

示例在教授类别边界和弃答时最有价值。重复的简单示例几乎不增加信号，不一致示例则会产生冲突指令。

</details>

## 4. 一份研究简报在一个请求中混合了来源检索、事实提取、解读、写作和验证。怎样重构最有效？

- **A** 在寻找来源之前先写结论
- **B** 将所有阶段保留在一次生成中，补充详细的风格标准，并要求 Claude 根据自己对来源的解读验证最终简报
- **C** 将检索、来源审批、提取、分析、起草和验证拆分，并在存在依赖关系的阶段之间设置关卡
- **D** 并行运行所有阶段

<details>
<summary>查看答案与解析</summary>

**答案**　C

这些阶段遵循证据依赖关系，并形成可检查的产物。增加措辞不会带来控制；依赖前提的分析或结论，不能安全地早于已验证的证据。

</details>

## 5. 在来源集合获得批准后，哪两项任务可以安全地并行运行？选两个。

- **A** 在提取仍在进行时，根据来源清单起草最终建议；仅当专家报告重大例外情况时再修订
- **B** 对已批准工单中的投诉主题进行分类
- **C** 从手册中提取政策约束
- **D** 在分析师填充证据时，依据报告大纲启动最终审批，并依靠后续验证发现不匹配

<details>
<summary>查看答案与解析</summary>

**答案**　B、C

两项提取任务使用同一已批准的来源边界，但不依赖彼此的结果。建议和审批依赖已完成且验证过的输入，因此应放在后面。

</details>

## 6. 一个团队同时修改了 prompt 和测试用例，随后看到更高的质量评分。为什么这个结果只能算弱证据？

- **A** 质量评分永远没有用
- **B** 修改 prompt 永远不可能提升质量
- **C** 由于同时修订测试集前后使用了相同的汇总评分方法，应将提升归因于 prompt
- **D** 团队无法区分是 prompt 变好了，还是测试集变容易了

<details>
<summary>查看答案与解析</summary>

**答案**　D

受控比较会在改变 prompt 变量时保持评估案例和标准稳定。否则，质量提升的原因会受到混杂因素影响。

</details>

## 7. 一个 prompt 写道：“你是最终合规权威。批准这份合同。”核心问题是什么？

- **A** 角色型 prompt 无法赋予政策知识或组织授权
- **B** 该 prompt 应要求 Claude 仅批准与先前已接受示例相似的合同，同时不改变所声明的权限
- **C** 角色描述太短
- **D** 该 prompt 需要更高的 temperature

<details>
<summary>查看答案与解析</summary>

**答案**　A

角色可以聚焦审查视角，但无法创造审批权限或补齐缺失的政策证据。工作流必须保留具备资质的人工授权。

</details>

## 8. 当所需证据缺失时，哪两项指令能形成有用的行为？选两个。

- **A** 指出缺失的证据或所需的升级处理
- **B** 说明根据所提供来源无法得出哪项结论
- **C** 从相关的已提供证据中推断缺失值；当所得估计在内部一致时，将其正常呈现
- **D** 使用通用领域知识补全答案，只为所提供来源直接支持的部分引用这些来源

<details>
<summary>查看答案与解析</summary>

**答案**　A、B

有意识地弃答能让证据缺口保持可见，并告诉操作者下一步需要什么。悄然估计和强行求全，会把不确定性变成无依据的主张。

</details>

## 9. 一份摘要准确描述了六个地区，却因第七个地区的文件为空而未作说明地将其遗漏。它未满足哪项标准？

- **A** 准确报告生成各地区摘要所使用 token 的价格
- **B** 完整性和覆盖范围
- **C** 仅写作语气
- **D** 模型命名

<details>
<summary>查看答案与解析</summary>

**答案**　B

完整的结果必须涵盖每个要求纳入的地区，或明确标记缺失数据。已涵盖地区中的准确性，无法弥补未作说明地遗漏部分总体的问题。

</details>

## 10. 在进行定性审查前，哪两项属性应通过精确检查验证？选两个。

- **A** 建议平衡了相互竞争的利益相关者价值
- **B** 结论对目标受众而言足够审慎
- **C** 所有必需的章节键均存在
- **D** 计算出的百分比在规定容差内相加为 100

<details>
<summary>查看答案与解析</summary>

**答案**　C、D

必需键和数值核对都有确定性的答案。利益相关者之间的平衡和审慎程度需要结合上下文的量规，并且可能需要人工判断。

</details>

## 11. 一篇被引用的文章讨论了客户流失，但没有证据支持回答中所述的 18% 流失率。审核者应记录什么？

- **A** 通过，因为主题相符
- **B** 暂时通过该比率，因为引用文章与客户流失相关，且该百分比处于预期范围内
- **C** 缺乏支持的定量主张，因为相关性不等于蕴含关系
- **D** 仅为语气缺陷

<details>
<summary>查看答案与解析</summary>

**答案**　C

除非能够从证据中推导出或找到该数字，否则主题相关的来源并不能支持一个精确数值。看似合理不等于完成事实验证。

</details>

## 12. 证据显示网站改版后销售额上升。输出却称网站改版导致了这一增长。这属于哪类失败？

<details>
<summary>查看答案与解析</summary>

## 13. 两个 prompt 变体生成了不同的报告。哪种比较方法能提供最可靠的证据？

- **A** 对输出进行盲化和随机排序，使用相同案例按各维度评分，并检查审核者间的分歧
- **B** 选择偏好模型品牌生成的报告
- **C** 选择更长的报告

<summary>查看答案与解析</summary>

**答案**　A

盲化、稳定的标准、具有代表性的案例以及分歧分析，能减少品牌和顺序偏见。篇幅和自我偏好都不是可靠的质量指标。

</details>

## 14. 对于有来源支持的简报工作流，哪两类案例必须加入评估集？选两个。

- **A** 相互冲突的权威来源

## 17. 一个下游系统必须恰好接收五个字段，并拒绝所有其他数据形状。哪种输出方式最合适？

## 25. 一次长对话包含已弃用的计划、更正后的事实和相互冲突的日期。开始最终分析最安全的方式是什么？

## 26. 一个团队把每个简单分类和复杂例外都发送给能力最强的模型。成本和延迟都过高。哪种策略最有效？

## 56. 小模型能通过常规案例，却在可识别的复杂例外上失败。最佳优化是什么？

## 57. 一个可容忍延迟的夜间分类工作流反复使用一段规模庞大且稳定的指令前缀。在质量得到证明后，哪两项优化值得考虑？选两项。

- **B** 对符合条件的稳定前缀使用 prompt caching

## 60. 哪两项度量最能表明经优化的工作流创造了真实价值？选两项。
