# 把每项事实放进正确的上下文 · 自测

每题先选答案，再展开解析。

## 1. 当前运营政策应以哪种机制作为权威来源？

- **A** 经过批准且持续维护的记录来源
- **B** 最新且完整的政策聊天
- **C** 在先前会话中曾产生正确答案的记忆偏好
- **D** 在政策来源确定为最新时生成的缓存回复

<details>
<summary>查看答案与解析</summary>

**答案**　A

运营事实应来自有负责人、已获批且保持最新的来源。上下文延续或复用机制不能充当权威记录。

</details>

## 2. 检索本身能确定什么？

- **A** 排名最高的片段具有权威性
- **B** 选中的片段看起来与查询相关
- **C** 来源完整、最新，而且适用于用户所在司法辖区
- **D** 已认证用户可以执行检索文本描述的任何操作

<details>
<summary>查看答案与解析</summary>

**答案**　B

检索只负责选择材料。权威性、完整性、新鲜度、访问权限和操作权限都需要单独检查。

</details>

## 3. 哪种内容最适合使用 prompt 缓存？

- **A** 每分钟刷新的实时库存表
- **B** 由集成代码跨多个用户会话复用的静态凭证块
- **C** 在大量调用中重复使用的大型稳定指令和参考资料前缀
- **D** 每次调用都会变化的客户专属请求和账号快照

<details>
<summary>查看答案与解析</summary>

**答案**　C

缓存最适合反复使用的大型稳定前缀。动态或敏感内容需要其他处理方式。

</details>

## 4. 一段长聊天中包含已放弃的计划和纠正过的日期。怎样继续最安全？

- **A** 保留全部历史，但在末尾添加一条新日期优先的指令
- **B** 使用偏向重复决策的自动摘要
- **C** 把相同历史移到上下文更大的模型中，以免丢弃先前推理
- **D** 用经过核验的决策简报和必需证据开启新上下文

<details>
<summary>查看答案与解析</summary>

**答案**　D

经过核验的简报可以移除冲突历史，同时保留当前决策和证据。

</details>

## 5. 连接器返回了一份较新的草稿，却与一份较早获批的政策冲突。工作流应该怎么做？

- **A** 应用已记录的来源层级，并暴露冲突
- **B** 合并不重叠的条款，并在冲突处暗中选择较新措辞
- **C** 优先使用草稿，因为来源不一致时，新旧程度是最可靠的默认标准
- **D** 接受草稿，因为连接器权限意味着其内容已经获批

<details>
<summary>查看答案与解析</summary>

**答案**　A

新旧程度、访问权限和权威性彼此独立。工作流应遵循明确治理规则，并暴露未解决的冲突。

</details>

## 6. 哪些登记表字段最直接支持知识生命周期控制？

- **A** 来源格式、页数、片段大小、检索分数和 embedding 版本
- **B** 负责人、权威性、生效日期、复核日期、敏感度和取代关系
- **C** 对话标识符、用户角色、写作语气、输出格式和缓存状态
- **D** 模型家族、prompt 版本、temperature、输出 token 和响应延迟

<details>
<summary>查看答案与解析</summary>

**答案**　B

这些字段可用于跟踪批准状态、新鲜度、权限、责任归属和退役过程。

</details>
